```
A Monotheist asks:
## John 17:3 — Now this is eternal life: that they know you, the only true God, and Jesus Christ, whom you have sent.
Trinitarians, can you confess with your mouth that the Father is the ONLY true God, and not Jesus or anyone else?
A Trinitarian replies:
Let’s answer this appropriately. Yes, the Father is the only true God, but Jesus didn’t say, “only the Father is the true God.”
Where you place the word “only” in a sentence matters. If I said, “2+2 only equals 4,” that is true. But if I said, “only 2+2 equals 4,” that is false, because 3+1 equals 4.
So we can say the Father is the only true God. The Son is the only true God. The Holy Spirit is the only true God. In fact, John said in 1 John 5:20 that the Son is true God. In John 17:3 eternal life is knowing Jesus and the Father, meaning eternal life comes from both of them, making them both God. The Gospel of John even opens by says Jesus is God (John 1:1). So this was never a problem for the sacred doctrine of the Trinity
```
