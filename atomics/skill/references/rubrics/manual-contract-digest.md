# NON-DROPPABLE DEFAULT MANUAL CONTRACT

This is the hot executable digest of the non-droppable default manual contract. Each numbered
law below is compressed executable rule, not commentary. The full clause text ships cold at
`references/rubrics/non-droppable-manual-contract.md` and is bound by `cold-law-manifest.json`
(sha256 per clause). If a full clause is needed but not loaded, route HOLD/PARTIAL with reason
`cold-law-not-loaded` -- never fake Land.

`field_witness` is the machine-readable graph/reconstruction payload. Normal governed output
includes `nodes`, `terminal_states`, `normalized_activation_record`, and `coverage_proof`; only
explicit minimal/short/no-graph modes may omit the payload, and they must say `graphing is unsupported`
or graphing is partial. The default proof tail remains public-first and literal: Restorative

`field_witness`. Never output only `PARTIAL / execution surface too small`, an `OUTPUT-LIMIT`, or
`practical response boundary` prose-only waiver in place of the public contract.

# EXECUTION MANDATE - DEFAULT MODE

Default mode suppresses raw visible IR but does not suppress recursive execution. Default mode is
scriptless compact DSL-governed execution. Do not call or simulate repo/dev route-check harnesses
during canonical execution.

HARD-COMPOUND LAYER B EXECUTION BODY: hard-compound full traversal requires a visible Layer B
operation body for every released burden. Do not collapse a major burden into one generic
"Bounded Response" paragraph. Each released submove carries Target, Operation, Result/state-change,
and Contribution-to-Land(Bn) as case-shaped prose, not stubs, naming the exact criterion/premise,
applying the matched owner/operator, and showing why that change contributes to Land(Bn). For
high-mass burdens include an explicit `TTP Operation Body:` with two visible prose movements:
owner execution, then field-state delta/Land connection. Fewer than three visible owner-bearing
submoves per released major burden in a 4+ burden hard-compound answer is an execution-depth
warning.

MANDATORY MRP ROUTE GATE: every routed burden-cycle that prints a concrete Land line, Field
diagnostics, LoopBreak, R(H,Delta), a next burden, HOLD/PARTIAL, or closure must print a compact
`[Mid-Reread Pressure]` block between the landed burden and the route. If the block is absent, do
not release the next burden, do not close, and do not print a route-bearing reread.

MRP ROUTE CONSEQUENCE INVARIANT: if MRP names remaining live pressure, non-neutral divergence,
non-null/held curl, a graph edge, or owner-body pressure, the output must release and land that
burden, explicitly HOLD it with a named gate/reason, or mark PARTIAL before any Restorative
Response or Closing Formulation. STOP/COMPLETE is invalid while the same MRP record names an
unresolved live pressure.

PARTIAL OWNER-LOAD BOUNDARY: when PARTIAL / OWNER-BODY-NOT-LOADED appears, do not continue into
broad refutation, Restorative Response, Closing Formulation, or closure witness for the blocked
burden. Give only the bounded diagnostic sketch licensed by loaded owners, name the missing
owner/path and next live burden, then stop.

MRP FIELD VALUE DISCIPLINE: field values are record values, not prose: `∇·T:
neutral|settled|bounded|non-neutral`, `∇×T: null|resolved|held|non-null`, `Finding:
stable|genuine-dependent|partial-real|hidden-framework-recoil|doubt-churn|reorientation`,
`Pre-emption basis: none|graph-bound|commitment-bound|framework-bound`, and `Route:
STOP|HOLD|RECURSE|LoopBreak(∇×T)`. `Pressure activations:` renders exactly six bullet slots:
`- freeze-landed-move:`, `- dependency-tug:`, `- hidden-framework-recoil:`,
`- entailment-pressure:`, `- doubt-churn-guard:`, and `- reorientation-reminder:`.

HARD-FULL PRE-CLOSURE GATE: before writing Closure/Reconstruction Witness with
coverage_complete=true in any 4+ burden hard-compound case, verify: the Layer B heading includes
Bounded or Governed; each non-atomic burden has at least three owner-bearing submoves; every
Land(Bn) is followed by inter-burden [Mid-Reread Pressure]; and the closure witness contains the
exact `T_lang: Ψᴺ ⇢ Ψᴵ` line. If any item fails, do not close; continue or route HOLD/PARTIAL with
coverage_complete=false.

BRANDOLINI DEFAULT: even non-hard-compound objections usually require more output than input.
Default responses to refute, respond, diagnose, shubhah, worldview, moral protest, hiddenness,
authority-order, or source-status inputs should render visible burden work, not terse answerlets.

Every plain `/daee-epistemics` runtime output begins with the noetic-field execution banner before
Layer A (exact frame reproduced below under Default Output Surface Invariant).
Clarifying or missing-input replies are still runtime outputs and must begin with the banner.
Print exactly one value for each field; never combine values with `|`.

`external source request` tracks explicit or implicit demand for citations or external grounding;
do not mark it `IMPLICIT` merely because a worldview or authority frame is live. Do not use
SIMPLE, COMPACT, CANONICAL, HARD, or SOURCE-ORDER as banner categories or depth licenses. `state`
is the opening governance state: RECURSE means live burdens remain and the output must continue;
PARTIAL means the output is stopping while live burdens remain unresolved; COMPLETE is allowed at
the opening banner only for a bounded case whose live burden set is already dischargeable in one
current pass. Closure audit must match the banner state.

Default multi-burden execution uses this repeated burden-cycle shape:
- Layer A - compact DSL/IR header (read status, confidence, claim_level, pattern_profile,
  reason-category, `Concealment mode:`, deformation, DO-orient, live noetic burden, current
  bounded operator, held, source-status/noetic-frame, gate/release decision with
  pre-release `∇ route: ...` when route ordering selects the burden; when more than one
  live/held burden or dependency route is present, the `∇ route:` clause is mandatory).
- Layer B - bounded governed response (Hidden Premises, local Core Formulation, Bounded Response
  / operative submoves, and TTP/operator trace when a named operator does runtime work; the
  released burden must be burden-complete before R).
- State/noetic re-read - compact. The visible state/noetic reread surface is the
  `[Mid-Reread Pressure]` activation record. It records `Land(Bn)`, remaining input-anchored
  burdens, held routes rechecked, target-explicit `∇·T` / `∇×T`, pressure activations, LoopBreak
  status, next live burden, route, and release status in prose.
- Named-worldview / source-authentication / mixed-field proof-tail witness accounts for
  candidate/held N frames, selected primary N, live registers, literal `Burden dependency
  graph:` with compact edges such as `B1 → B2, B3` or `B1 ∥ B2 → B3`, and remaining kappa / H
  status. If any live dependency remains unresolved, write PARTIAL or continue under RECURSE.
- Restorative Response - required once after the final state/noetic re-read.
- Closing Formulation - required once at the end after final Restorative Response.

General noetic-selection / register-control reread gate:
do not assume the selected N frame is known at design time. For any input, scan the
noetic-structure selection space and treat heart,
xi, Omega, sigma, mu, kappa, and H as live whenever the input supports them.

SOURCE-AUTHENTICATION and ask for the missing material after the banner; do not mark it

Short named-worldview hard-field gate: noetic-structure hardness is not proportional to prompt

Current bounded operator names one live noetic burden/function, not a route chain or module list.
Operative submoves are not burden-cycles. A live noetic burden may contain multiple operative
submoves, each preserving target -> operation -> result, before the burden lands and state is

Rewrite before emitting.
