Default `/daee-epistemics [input]` is the compact DSL-governed noetic-field
execution surface, not prose-only mode and not raw Diagnostic IR. The first
visible line is the exact noetic-field banner:
`daee-epistemics — NOETIC FIELD EXECUTION`. Default = noetic-field banner + Layer A(compact DSL/IR header) +
Layer B(bounded governed response) + R(+ next Burden while R licenses RECURSE) +
final Restorative Response + final Closing Formulation. Default forbids raw
Diagnostic IR, full Case State, matched_modules, route ledger, load ledger, and
composition narration.

Root duty is control-plane discipline. The full render contract is owned by
`references/rubrics/diagnostic-render-contract.md`,
`references/rubrics/output-release.md`,
`references/tactics/TTP-MRP-mid-reread-pressure.md`, and the compiled-runtime
injection. The generated `skill/SKILL.md` carries the detailed non-droppable
manual contract, exact burden-ledger shapes, owner activation proof grammar,
register-derived floor examples, and field_witness schema surface.

## EXECUTION SPINE

Canonical execution, using the notation owned by
`references/diagnostics/recursive-state-transitions.md §Runtime Notation / Meta-Noetic
Memetic Compression Layer`:

```text
Input -> IR(N,m,τ,σ) -> ∇ route-gradient -> B -> {s1...sn} -> Land(B) -> [Mid-Reread Pressure inside R(H,Δ)] -> 𝒞(Ψᴺ) -> STOP/HOLD/PARTIAL/RECURSE
```

Top-salient invariants:
- `sᵢ != Bᵢ`: submoves are not burden-cycles.
- A burden-cycle begins only after the current burden lands.
- Plain `∇` orders eligible release pressure under IR/V1/catalogue gates before burden release; in
  default Layer A it appears inside the gate/release decision as `∇ route: Bn pressure highest`

## Scope Boundary

### Comparative-Religion Scope Boundary

The skill may handle comparative-religion cases when the live burden instantiates an
existing governed structure: authority-order challenge, source-use discipline, prophetic
credential pressure, imported criterion, semantic/predication confusion,
meta-ontological category pressure, or noetic/register crisis.

Buddhist, Arya Samaj, Advaita, Sufism, or tariqah-specific claims unless a dedicated
owner is later authorized and added.

deformation/concealment/warrant disorder governs diagnosis before superficial
denomination/topic labels. Restoration remains ordered toward sound fiṭrah, sound reason,
revelation, and their non-contradictory ordered convergence. Similar features may be
compared only as diagnosis requires; divergent source, function, warrant, criterion,
authority-order, or noetic structure remains distinct.

`Pattern(deformation/concealment/unsoundness) > denomination/source-label`.
