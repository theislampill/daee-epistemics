# v0.4.5.0 Release Notes

v0.4.5.0 is the v0.4.x Skill-as-Code structural-integrity hardening release on
the `0.4.0.0` operative contract line.

## Summary

On 2026-06-18, the original v0.4.5.0 public release was replaced after a
secularism ACT/MRP false-green audit found that visible output could present
round-robin ACT owner-slot coverage while sidecars and a terminal MRP made the
run look green.

The repaired v0.4.5.0 release keeps the same version line, retargets the tag to
the hardening source commit, and replaces the public `.skill` and provenance
assets after the historical false-pass became an invalid fixture and the
all-at-once Smoke C matrix passed 4/4.

## What Changed

- Added the attached secularism false-pass as
  `tests/mrp-route-invariants/invalid/secularism-round-robin-act-terminal-mrp-false-pass.md`.
- Hardened visible ACT/MRP route invariants against non-contiguous burden groups,
  repeated terminal `Land(Bn):` gates without immediate MRP, terminal MRP covering
  multiple earlier Land gates, false `no_new_resultant`, and sidecar laundering.
- Preserved the semantic distinction between submove-local
  `Contribution-to-Land(Bn)+` and terminal public `Land(Bn):`.
- Repaired Stage05 continuation normalization so non-final
  `STOP/no_new_resultant` cannot remain when later burdens are already live.
- Added parser-stable Stage05 diagnostic punctuation normalization without
  weakening route-state checks.
