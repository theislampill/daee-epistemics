  TTP.

  secularism/authority-order smoke.
- Raw smoke output `tests/smokes/mrp-behavior/outputs/smoke6-hard-repair14-v0.4.3.0.md` is local
  evidence and is not committed or uploaded as a release asset.

- The Trinitarian RC2 smoke found three targeted issues: STOP before B4 continuation, `∇×T`
  misuse for linear chains, and mixed-field classification drift. These were fixed and then
  generalized so the invariant is not Trinitarian-specific.
- A later secularism exact-file hosted smoke passed the generic route/curl/field checker, but that
  smoke is not claimed as a fresh full reconstructibility proof.
- The generated-burden / notation hotfix adds deterministic fixture/checker proof that
  `held_burden_activation` is distinct from `generated_burden_instantiation`. It does not claim a
  fresh hosted Smoke 7 model-output proof.
- Cross-host/paraphrase proof remains future work.
