Graph a Skill Output

This tool consumes a finished output. It does not change runtime behavior, invoke the skill, or prove live model behavior. It makes visible whether an output is graphable, reconstructible, and terminally accounted.

Validation

    Warnings

      What It Checks

      Hard errors: missing initial burdens under complete closure, unknown graph nodes, missing terminal states, STOP before later burden work, unbacked MRP-governed graph edges, decorative MRP labels, live ∇·B or ∇×κ under complete closure without a licensed route.

      Warnings: legacy ASCII aliases such as B1 -> B2, burden notation written as B₁, missing submoves under a full landing, held-burden activation without generated burden, low visible topology, possible bloat, or visible/field_witness mismatch.

      Notation boundary: public output should prefer ¹B, ¹B₁[OP], Land(¹B), MRP(¹B), ¹B → ²B, ∇·B, ∇×κ, 𝒞(Ψᴺ), and T_lang: Ψᴺ ⇢ Ψᴵ. Parser aliases are fallback only. Mermaid export is optional/lossy and includes an ELK layout hint; it is not the primary renderer.
