Current Bridge Note

The notation layer is schema-light baseline control over the compact runtime.
The registers are not mandatory JSON fields unless a deliberate contract migration updates producers, consumers, schemas, tests, examples, docs, generated runtime, and release claims together.

Use the notation to clarify where a live register changes IR, owner eligibility, held material, collapse radius, burden landing, reread, PARTIAL, or restoration.
If it does not change control state, it belongs in deeper theory or reference material, not in the Architecture map.
