# v0.4.1.0 Release Log

## Release Scope

v0.4.1.0 prepares a cleanup/hardening release candidate on the `0.4.0.0`
operative contract line. The release scope is governance, docs consolidation,
formalism operativity auditing, CI artifact-build automation, and local package
provenance.

## Included Changes

- Root `atomics/skill/SKILL.md` remains below the control-plane drift budget and
  points detailed banner/release/reread rules to the actual owner files.
- The noetic-field banner, algebraic-control, and explanation-faithfulness
  invariants remain source-owned and checker-enforced.
- Historical audit and release surfaces are consolidated into history files
  while preserving provenance.
- Level3 active execution language is deprecated; compatibility harness
  filenames remain until a separate coordinated harness rename.
- Branch-era pipeline labels are removed from active architecture language;
  compatibility checker wrapper remains for old command paths.
- Manual `release-skill.yml` builds artifacts from atomics, writes provenance,
  and does not publish releases or create tags.
- Generated `skill/**` is untracked and ignored; CI/local release builds now
  regenerate it from tracked atomics before packaging.

## Verification Plan

The final gate runs the structural checker suite, register-formalism checker,
compatibility wrapper, Python tool compilation, diff checks, local package build,
archive shape inspection, provenance generation, and stale-reference sweep.
