# Release Documentation

This directory keeps release history out of the active docs root while preserving provenance in consolidated history files.

- `release-history-v0.3.md` consolidates archived v0.3.x release evidence.
- `release-history-v0.4.md` consolidates archived v0.4.x release evidence.
- `../v0.4.5.0-release-notes.md` and `../v0.4.5.0-release-log.md` record the
  ACT/MRP false-pass repair replacement, package/provenance readback, and
  Smoke C four-smoke closure.
- `../v0.4.4.0-release-notes.md` and `../v0.4.4.0-release-log.md` record the
  Gate88 four-smoke closure and retained proof-promotion release.
- `../v0.4.2.0-release-notes.md` and `../v0.4.2.0-release-log.md` are pre-public
  candidate surfaces for the Deep Research implementation / evidence-discipline release; local
  package/provenance and the minimal three-case smoke skeleton remain pre-public and are not
  publication authorization until the local package-bound smoke gate passes.
- `../v0.4.1.0-release-notes.md` and `../v0.4.1.0-release-log.md` remain the prior corrected
  v0.4.1.0 release surfaces.
- Current package artifact metadata remains in `../release-artifacts.md` until a future release metadata migration is approved.
- Do not recreate per-release historical logs/notes unless a new current release is being prepared and explicitly authorized.
