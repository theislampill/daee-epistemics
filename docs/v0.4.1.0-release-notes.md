# v0.4.1.0 Release Notes

v0.4.1.0 is a cleanup and hardening release on the `0.4.0.0` operative
contract line. It does not introduce a hard schema/register migration and does
not untrack generated `skill/**` runtime output.

## What Changed

- Consolidated docs, audit, and release-history surfaces so current guidance is
  smaller and historical evidence remains preserved in history files.
- Deprecated active Level3 wording. Legacy route/check harness filenames remain
  compatibility details for maintainer workflows, not public runtime identity.
- Deprecated active branch-era pipeline labels in favor of the schema-light
  register-formalism bridge and compact DSL/IR runtime spine.
- Added final-gate audits for algebraic notation operativity, divergence/curl
  diagnostic boundaries, root SKILL/DSL/IR/NLA compliance, TTP/module
  operativity, and CI/release workflow behavior.
- Added a manual GitHub Actions artifact workflow that builds from atomics into
  the consolidated runtime package and uploads workflow artifacts only.

## What Is Not Claimed

- No GitHub Release has been published by this candidate worktree.
- No hard register fields are added to Diagnostic IR.
- No generated `skill/**` untracking is performed.
- Ignored local smokes and retained `.daee` evidence remain local evidence, not
  package/release proof.
- Divergence/curl language is audit/formalism visibility with control
  implications, not default decorative runtime notation.

## Package

The package is generated from `atomics/skill/**` through the generated
`skill/**` runtime into the consolidated skill artifact. Candidate artifact
metadata is recorded in `docs/release-artifacts.md` after the local package
build.
