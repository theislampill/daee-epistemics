## Current B.5 State

B.5 previously proved bounded NLA semantic faithfulness: visible ACT records
can be parsed into checker-owned `CanonicalActivation` slots, dereferenced to
the matching Layer B body, compared against `field_witness.owner_activations`,
and reconstructed into verifier-passable Layer B submoves.

That was useful but intentionally not full IR decode. It did not prove that a
complete machine-readable IR projection could be recovered from output-level
evidence, especially when hard-register state was present.

## A.13.1 / A.13.2 Prerequisites

A.13.1 added the explicit hard-register schema marker
`diagnostic_ir_schema_version = "0.4.3-hard-registers-v1"` and canonical hard
register keys:

- `heart`
- `xi`
- `Omega`
- `mu`
- `kappa`

A.13.2 then added checker/fixture reconciliation between the hard-register v1
object, `field_witness.normalized_activation_record.live_registers`,
`field_witness.register_deltas`, and
`coverage_proof.diagnostic_completeness`.

These two slices make a B.5 projection gate possible without requiring ordinary
runtime governed output to emit hard registers by default.

## Target Model: Canonical IR Projection

`field_witness.canonical_ir_projection` is an optional B.5 reconstruction
object. When present, it states the IR-level slots that the checker can recover
from the visible output plus field witness:

- selected N-frame;
- live register set;
- burden floor;
- per-burden normalized activation rows;
- diagnostic-completeness coverage;
- optional hard-register v1 state when the hard-register marker is present.

The object is intentionally optional. Existing schema-light outputs remain
valid when it is absent.

## What the Checker Proves Now

`tools/check_nla_decode_semantic_faithfulness.py` now validates
`field_witness.canonical_ir_projection` when an artifact elects to provide it.
The checker verifies:

- the projection schema marker is current;
- projection N-frame, live registers, burden floor, per-burden rows, and
  diagnostic-completeness object mirror `normalized_activation_record` and
  `coverage_proof`;
- projection per-burden rows decode to visible ACT rows by burden, owner family,
  operation, and delta result;
- route-result and terminal-state tokens are controlled;
- generation depth is a non-negative integer;
- hard-register projections require the A.13 v1 marker;
- hard-register v1 live/held state reconciles with projection live registers,
  NAR live registers, live `register_deltas`, and diagnostic completeness.

## What Remains Future / Protected

B.5.1 does not claim:

- default runtime emission of hard-register fields;
- full IR decode for arbitrary governed outputs;
- a standalone natural-language-to-IR parser;
- full register-level machine-checkable decode across all retained corpus cases;
- full IR decode implementation for package/provenance claims;
- guaranteed `T_lang` uptake;
- cross-host or paraphrase proof.

Those remain protected future choices and require explicit owner approval.

## First Implementation Slice

The first implementation slice is B.5.1:

- add optional `canonical_ir_projection` validation to the NLA decode checker;
- add schema-light positive projection fixture;
- add hard-register v1 positive projection fixture;
- add invalid canaries for missing hard-register live set, NAR live-set
  mismatch, `register_deltas` mismatch, diagnostic-completeness mismatch,
  hard-register object without version marker, and invalid owner/delta/MRP route
  projection.

## Risks / Stop Conditions

Stop if:

- schema-light NLA fixtures are forced to emit hard-register state;
- hard-register projection validation starts acting as runtime/default emission;
- checker green output is described as full IR decode;
- projection rows can pass without visible ACT/body evidence;
- projection hard-register live state can drift from NAR, register deltas, or
  diagnostic completeness;
- package, tag, upload, release, provenance, D.8 cleanup, model smokes, or
  runtime/default hard-register emission are accidentally opened.

a proof-mode retained governed artifact, open the smallest runtime/default
machine-facing emission path that could produce such artifacts later without
weakening B.5.3 v1.

Implemented contract:

- `field_witness.canonical_ir_projection.emission_policy` is an optional
  machine-facing policy object with schema `b5-full-ir-runtime-emission-v1`.
- The policy is separate from B.5.3 `proof_mode`. B.5.3 proof-mode v1 keeps
  `default_runtime_emission_claim: false`; the new policy records the default
  runtime expectation for new proof-class closure outputs.
- The policy is valid only with `proof_mode`, `decoded_ir`, and
  `full_ir_decode`; it is not a standalone parser or prose replacement.
- New proof-class closure governed outputs must emit the projection stack
  when the fields can be populated from visible ACT rows, NAR, and
  field-witness evidence.
- Historical schema-light retained outputs remain valid absent the projection
  stack, and the visible noetic-field banner plus compact Layer A / Diagnostic
  IR header remain mandatory for projection-bearing output.
