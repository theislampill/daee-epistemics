# v0.4.1.0 Pipeline-Label Deprecation Audit

## Purpose

Deprecate branch-era `Pipeline #1` / `Pipeline #2` language from active
v0.4.1.0 architecture surfaces. Historical evidence may retain the labels, but
active docs, runtime governance, CI, release-candidate text, and user-facing
architecture now use the stable concept name:

- `schema-light register bridge`
- `register-formalism bridge`
- `algebraic noetic-state bridge`
- `register-derived control over existing IR`

This is a debranding and consolidation pass, not a runtime doctrine change.
