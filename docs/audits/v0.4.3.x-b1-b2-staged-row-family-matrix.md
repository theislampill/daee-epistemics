## Output Assembly Policy

Proof-class staged outputs should be Brandolini-expanded where the case
warrants it. Complex cases should target 70-100KB+ and the harness must permit
compiled outputs of at least 200KB.

The final `output.md` must be assembled by code from bounded section artifacts
rather than depending on one model message to produce the whole final answer.
The assembly manifest schema is `staged-governed-output-assembly-v1`.

No assembled output is proof by itself. Validators and sidecars remain the
proof gates:

- Stage 07 validators run against the compiled `output.md`.
- Stage 08 sidecars build only after Stage 07 passes.
- Retained promotion runs only after checker-owned sidecars pass.
- Failed `.daee` outputs are negative evidence and must not be hand-edited into proof.

## Stop Conditions

Stop and record the exact blocker if any of these occur:

- baseline checks are unclear broken;
- compiled output cannot preserve the public governed output surface;
- assembly would require the compiler to author reasoning instead of assembling sections;
- Stage 07 validators require trusting model-authored proof claims;
- Stage 08 sidecars fail;
- retained promotion would require hand-editing output;
- schema-light retained cases become invalid;
- output-size handling cannot be validated safely;
- a broad closure claim would exceed evidence;
- package/release/provenance/D.8/broad-matrix work becomes necessary.
