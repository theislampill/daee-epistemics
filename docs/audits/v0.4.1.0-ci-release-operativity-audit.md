## Algebraic Symbol Operativity Gate

CI/release readiness now depends on the checker-parsed audit
`docs/audits/v0.4.1.0-algebraic-symbol-operativity-audit.md`. The register-formalism checker
fails if any required algebraic/register/governance symbol is missing from the table, lacks an
approved classification, lacks an owner, or claims OPERATIVE/AUDIT_DIAGNOSTIC_ALLOWED status
without a named control effect. The same checker also requires fixture-matrix coverage for local
transition, register activation, held frame, closure prevention, divergence/curl,
anti-symbol-theater, and Shannon/NLA boundary cases.

NLA is separately gated as Natural Language Autoencoder, not as generic algebra/Shannon language:
`docs/audits/v0.4.1.0-nla-operativity-audit.md` and fixture
`13-nla-verbalizer-reconstructor-mapping` must prove AV/AR analogues, reconstruction fidelity,
confabulation warnings, and default-runtime absence of NLA jargon.

CI now treats divergence/curl operativity as a structural formalism-checker
obligation, not a prose-only audit claim.

| operator form | classification | CI/release gate |
|---|---|---|
| `∇·` | AUDIT_DIAGNOSTIC_ALLOWED / DEFAULT_COMPACT_STATE_MARKER_ALLOWED / DEFAULT_FORMALISM_EXPOSITION_FORBIDDEN | `tools/check_register_formalism_bridge.py` fails if omitted from the formalism audit/fixture, if used without control context, or if expanded exposition appears in default runtime surfaces. |
| `∇×` | AUDIT_DIAGNOSTIC_ALLOWED / DEFAULT_COMPACT_STATE_MARKER_ALLOWED / DEFAULT_FORMALISM_EXPOSITION_FORBIDDEN | `tools/check_register_formalism_bridge.py` fails if omitted from the formalism audit/fixture, if used without control context, or if expanded exposition appears in default runtime surfaces. |

| `del-cross`, `del cross`, `curl`, `nabla cross` | AUDIT_DIAGNOSTIC_ALLOWED / DEFAULT_FORMALISM_EXPOSITION_FORBIDDEN | Alias forms are required in audit/formalism operator detection; they are not compact default notation except as plain gloss. |
| historical prose occurrences | HISTORICAL_ONLY | Not a CI proof of operator-family operativity. |
| decorative math without control effect | ORNAMENTAL_RISK | Fails when no `R(H,Delta)`, PARTIAL/RECURSE/COMPLETE, dependency-radius, loop/circulation, or held-burden effect is named. |

Release implication: divergence/curl remain field-level diagnostics, not Delta replacements. Compact `∇·κ` / `∇×κ` markers must surface by default when control-relevant; long formalism exposition remains audit/formalism only. They are operative only where the checker can see that they affect `R(H,Δ)`, dependency handling, owner/TTP routing, held-burden release, closure state, or checker outcome. The manual artifact workflow must build the generated runtime first, then run the checker before packaging.
