# v0.4.1.0 Release-Claim Integrity Audit

## Standard

This audit enforces:

```text
claim -> evidence -> checker/provenance -> qualifier
```

It rejects:

```text
claim -> broad prose token -> later hardening needed
```

Scope is reporting accuracy only. This audit did not trim the skill, reduce runtime content, remove TTPs, delete evidence, change package shape, change atomics, change generated-runtime behavior, mutate GitHub Release bodies/assets, move tags, push, package, or release.
