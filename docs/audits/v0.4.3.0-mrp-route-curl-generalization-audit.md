# v0.4.3.0 MRP Route/Curl Generalization Audit

## Executive verdict

TRINITARIAN FIX WAS CASE-SPECIFIC; GENERIC PATCH APPLIED

## Scope

This follow-up audits whether the Trinitarian RC2 hotfix generalized into runtime invariants rather
than remaining a case-specific patch.

The audited invariants are:

1. `Route: STOP` forbids later Layer B burden work or graph continuation.
2. Closure graph edges must be backed by MRP graph/resultant and route records.
3. Directed acyclic downstream burden pressure belongs to `∇·T`, while `∇×T` is reserved for real
   loop/churn/recoil/rotation pressure.
4. A named theological/worldview authority frame plus active Islamic restoration must not flatten to
   `LOCAL CLAIM`.

## Was it hardcoded?

Partially, before this audit.

The prior Trinitarian hotfix added useful source-owner guidance, but several normative examples used
case-shaped wording such as `B3 -> B4`, `B2/B3/B4`, and Trinitarian/tawḥīd-specific field phrasing.
The checker also owned invariant logic in `tools/check_trinitarian_mrp_hotfix.py`, making the proof
too dependent on the Trinitarian fixture family.

Classification of hardcoding search:

| Hit class | Classification | Action |
| --- | --- | --- |
| Case-library references to Trinity/Trinitarianism | allowed source content | unchanged; these are actual Christian-case owners |
| Source-owner route examples using `B3 -> B4` or B1/B2/B3/B4 as normative language | suspicious source-owner hardcode | replaced with generic `Bn -> Bn+1` / later-burden wording |
| Field rule phrased as Islamic tawḥīd-only | narrow source-owner phrasing | generalized to Islamic restoration frame |
| `tools/check_trinitarian_mrp_hotfix.py` owning route/curl logic | suspicious checker hardcode | replaced with wrapper around generic checker |
| Trinitarian fixtures and audit docs | allowed fixture/audit-specific | retained |

## Generic invariants verified

Generic source owners now encode:

- if later burden work or a closure graph edge follows, the previous MRP record is not final STOP;
- remaining downstream burdens require `genuine-dependent` or `partial-real`, graph delta, and
  `RECURSE` or `HOLD`;
- directed acyclic chains are `∇·T` pressure, not `∇×T`;
- `∇×T` held/non-null/resolved requires an actual curl-like reason;
- named theological/worldview authority plus Islamic restoration is mixed-field, not local-only.

The generated compiled-runtime guidance was rebuilt from the generic source wording.
