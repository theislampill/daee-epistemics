# v0.4.3.0 Smoke Regression Comparison

## Evidence boundary

Reference files inspected only:

- `C:\Users\theis\Downloads\v.4.2.0 smoke.md`
- `C:\Users\theis\Downloads\v.4.3.0 smoke.md`

No live smoke was generated for this comparison, and no raw smoke output is copied here.

## First-visible surface

v0.4.2.0 begins with a governed execution box whose second visible line names
`daee-epistemics - NOETIC FIELD EXECUTION`, followed by explicit `field`, user
task, source request, authority frame, and state fields.

v0.4.3.0 begins with a fenced plain `field:` block. It preserves the same basic
metadata fields, but the first-visible governed-execution signal is flattened.

Assessment: regression confirmed. The v0.4.3.0 first-visible surface treats
plain `field:` as sufficient, while v0.4.2.0 signals active governed runtime.

## Layer A / Layer B structure

v0.4.2.0 renders a global `Layer A - Compact DSL/IR Header`, then a governed
`Layer B - Bounded Governed Response`, and re-enters Layer A for later burden
rereads.

v0.4.3.0 renders per-burden headings such as `Burden 1 - Layer A` and
`Layer B - Burden 1`. The shape remains structured, but the first pass reads
more like organized prose than a governed execution surface.

Assessment: partial retention with behavioral flattening.

## Submove notation and quantity

v0.4.2.0 visibly renders worked submoves such as `1B1 [FPD]`, `1B2 [M1]`,
`1B3 [M1-P]`, and further burden-local submoves before landing each burden.

v0.4.3.0 does not show `1B`-style submove notation in the smoke. It uses prose
labels such as `Operative Submove - M1/M1-P`, which preserves some operator
identity but loses the explicit burden/submove accounting surface.

Assessment: regression confirmed. The worked `nBi[OPi]` surface no longer
appears in the observed v0.4.3.0 live behavior.

## Land(Bn) and R(H,Delta)

v0.4.2.0 explicitly renders `Land(B1)`, `Land(B2)`, `Land(B3)`, `Land(B4)`,
`Land(B5)`, and `R(H,Delta)` after burden landings.

v0.4.3.0 uses state reread prose such as `burden landed`, `remaining`, and
`release status`, but does not visibly render `Land(Bn)` or `R(H,Delta)` in the
same invocation-time form.

Assessment: regression confirmed. Landing and reread semantics are present as
ideas, but not as the canonical visible burden-cycle gate.

## MRP and field diagnostics

v0.4.2.0 visibly uses field diagnostics and curl/divergence-style rereads in
later burden passes, including post-landed `Field diagnostics` and `LoopBreak`
language.

v0.4.3.0 includes field diagnostics prose, including active curl language, but
the smoke comparison does not show a visible `MRP` activation block or an
explicit mid-reread pressure gate before closure, HOLD, or RECURSE.

Assessment: MRP appears architecturally present but behaviorally under-triggered.

## Burden dependency progression

v0.4.2.0 decomposes the hard case into a dependency-sensitive sequence:
imported tribunal first, then accountability compression, hiddenness/coercive
guidance, predication repair, and source-worldview analysis.

v0.4.3.0 preserves a five-burden progression, but the per-burden executions are
less visibly tied to explicit submove accounting, `Land(Bn)`, and `R(H,Delta)`.

Assessment: progression survives, but the noetic reread machinery is less
operational on the visible surface.

## Closure witness quality

v0.4.2.0 closes after all five input-anchored burdens are discharged and shows
explicit burden dependency closure.

v0.4.3.0 reaches a coherent conclusion, but the visible path to closure relies
more on prose-level state labels than on the canonical burden-cycle witness.

Assessment: closure quality is weaker because the proof of governed execution is
less auditable from the primary surface.

## Preliminary regression thesis

The observed smoke comparison supports the thesis that v0.4.3.0's compaction
made source architecture cleaner while removing invocation-critical cues from
the primary runtime surface. The likely repair is not a broad rollback. It is a
compact restoration of:

- governed first-visible banner or equivalent execution signature;
- inline worked `nBi[OPi]` submove example in root `SKILL.md`;
- explicit `Land(Bn)` before reread/routing;
- MRP trigger visibility when post-reread pressure is non-neutral or curl is non-null.
