## D3 problem (recap)

Every staged-compiled output in the retained corpus (four Gate88 cases plus
the staged secularism pilot) renders a single terminal `[Mid-Reread Pressure]`
block for 4-12 public `Land(ⁿB):` landing gates, while
`field_witness.formal_reread_states[]` carries per-burden reread records. The
canonical contract requires one visible block per routed burden-cycle. All 19
chat-shape corpus outputs satisfy gates == blocks exactly.

## Producer Gemba (root cause, line-exact)

- `tools/build_staged_governed_output.py:40-57`: `mrp_reread_terminal` is a
  SINGLETON role in `ROLE_ORDER`; no per-burden MRP section type exists. One
  terminal block is the assembler design, not a model lapse.
- `tools/run_staged_current_skill_smoke.py:2708-2806`
  (`stage07_mrp_contract_guidance` / `mrp_block_lines`): the harness
  pre-renders the public MRP block scaffold one-per-`mrp_resultants[]` row.
  Stage-05's singular `reread_state` collapses per-burden rereads into one
  terminal resultant, so one block is scaffolded. The scaffolded block also
  emits `Pre-emption basis: terminal states landed; B_MRP empty; no generated
  burden remains` (line 2754) — the exact invalid token rejected by
  `check_mid_reread_pressure` — and contains no `Pressure activations:` slots.
- Self-test lockstep: `run_staged_current_skill_smoke.py:9129-9150` asserts
  the scaffold strings verbatim, including the invalid pre-emption literal
  (line 9140). Any scaffold canonicalization must update this expectation
  list in the same change.
- Release-validator coupling: `run_release_validators`
  (`run_staged_current_skill_smoke.py:11591-11645`) is executed by the runner
  self-test against a self-test compiled output (line 5369), so adding
  `mid_reread_pressure` to `STAGE07_RELEASE_VALIDATION_ORDER` (lines 131-141)
  requires the scaffold fix in the same change or the self-test goes red.
- Handshake key sets: `check_staged_runtime_handshake.py:154-166`
  (`STAGE07_RELEASE_VALIDATION_KEYS` required / optional split). No valid
  fixture carries `release_validation`, so adding the required key is
  fixture-safe once the runner emits it.
- Data availability: `formal_reread_states[]` carries 11 of 13 visible block
  fields per burden; `finding`, `boundary`, and all six pressure-activation
  slots are MISSING from machine records. Per-burden visible blocks therefore
  cannot be reconstructed harness-side without fabrication — the producer
  record must carry them. North Star class 1 (producer/scaffold failed to
  emit DSL), confirmed at source.

## Slice A — implemented and verified (no-model)

1. `tools/check_mid_reread_pressure.py`: new per-Land coverage rule
   (`per_land_mrp_coverage_errors`): every line-start `Land(ⁿB):` landing
   gate must be followed by a `[Mid-Reread Pressure]` heading before the next
   gate (or end of output). Closes the false-negative where a single
   well-formed terminal block would have passed. Empirical separation
   preserved exactly: 19/19 chat-shape corpus outputs pass; the same 5
   staged-shape outputs fail, now with explicit per-gate coverage errors.

   frozen Gate88-shape canary (two gates, one valid terminal block) —
   rejected by the checker (invalid fixtures 23 -> 24).
3. `tools/check_staged_runtime_handshake.py`: stage-05 `per_burden_reread`
   contract (optional in schema, shape/vocabulary validated when present):
   one entry per landed burden mirroring the 13 visible block fields plus the
   six fixed `pressure_activations` slots, controlled finding/route/
   route-result/pre-emption vocabularies, `R(H,Δ)`/`Δ` anchors, and the
   `T_lang` boundary prefix. Fixtures:
   `tests/staged-runtime-handshake/valid/stage05-per-burden-reread.json`
   (accepted; valid 20 -> 21) and
   `tests/staged-runtime-handshake/invalid/stage05-malformed-per-burden-reread.json`
   (rejected; invalid 90 -> 91).
4. D10: README file-retained section now states the canonical hard-case
   transport boundary and that per-burden MRP visibility applies identically
