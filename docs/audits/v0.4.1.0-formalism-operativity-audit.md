## Divergence / Curl Operativity
1. Where defined: `docs/algebraic-notation-and-noetic-formalism.md` now owns the divergence/curl diagnostic boundary; `tools/check_register_formalism_bridge.py` requires the section tokens, so removing the boundary changes checker outcome.
2. Visibility: divergence/curl are default-visible only as short, control-bound state markers when governance requires them. Default runtime remains banner + Layer A + Layer B + `R(H,Δ)` / closure state, and long formalism exposition remains audit/formalism visibility.
3. Behavior: `Delta-nB` and `Delta-kappa` are event-local operative deltas. Divergence/curl read the field those deltas produce across burden sets; they affect release/hold/closure only when they identify expanded dependency pressure or self-reinforcing loops that require RECURSE/PARTIAL.
4. Checker outcome: the register-formalism checker fails if the source boundary tokens are removed; the formalism audit classifies default-output decorative use as symbol theater.
5. Generality: the diagnostic is generalized across selected/held noetic frames. Secularcompact is a regression example, not the template.
6. Boundaries: anti-symbol-theater and Shannon-boundary warnings forbid treating divergence/curl as proof of truth, meaning, warrant, revelation, fitrah, or sound reason.
7. Verdict: OPERATIVE as checker-enforced field diagnostics with control implications; compact markers may appear by default when control-relevant, while decorative or explanatory formalism remains forbidden.

## Delta / Divergence / Curl Operator Distinction

1. `Delta-nB` and `Delta-kappa` are event-local transition operators.
2. `∇·` and `∇×` are field-level diagnostics over the burden/dependency/register state produced by `Delta-nB` and `Delta-kappa`.
3. `∇·` reads expansion/contraction/source-sink pressure across the field after burden landing and reread.
4. `∇×` reads circular/antisymmetric/self-reinforcing dependency circulation across the field.
5. `∇×` remains meaningful in high-dimensional noetic-state space through the antisymmetric part of the Jacobian / exterior derivative analogy; it is not dismissed merely because standard vector-calculus curl is a 3D construction.
6. Neither `∇·` nor `∇×` replaces `Delta-nB` or `Delta-kappa`.
7. None of these operators are allowed as symbol theater.
8. The operators are operative only when they change `R(H,Delta)`, dependency handling, owner/TTP routing, held-burden release, PARTIAL/RECURSE/COMPLETE, or checker outcome.
