# v0.4.3.0 Closure Witness Graph Audit

## Executive verdict

CLOSURE WITNESS GRAPH IMPLEMENTED

## Goal

Make closure/collapse reconstructibility checkable from output alone. The visible
`Closure/Reconstruction Witness` exposes a parseable burden dependency graph, and the
`field_witness` sidecar exposes the same graph and terminal accounting as machine-readable JSON.

## Grammar

Canonical closure witness graph notation:

- `(root)` means the burden has no upstream dependency.
- `A → B` means B depends on A landing first.
- `A ∥ B` means A and B are parallel / independent at this level.
- Every graph node must correspond to a burden ID in terminal-state accounting.
- The graph must be reconstructible from visible witness text without hidden state.

Valid example:

```text
B1 (root)
B1 → B2
B1 → B3
B2 ∥ B3
B2 → B4
B3 → B4
```

Counterexamples: `B1 then maybe B2`, `B1/B2 related`, and `B2 after the first thing`.

## Parser behavior

`tools/closure_witness_lib.py` now parses visible closure witness text into burden nodes, roots,
dependency edges, parallel groups, terminal states, register notes, `∇·B` / `∇·T`, `∇×κ` / `∇×T`,
`𝒞(Ψᴺ)`, and `T_lang: Ψᴺ ⇢ Ψᴵ`. It rejects unparseable graph prose, unknown graph nodes, missing terminal
states, roots with upstream dependencies, missing root markers, and cycles.

The same library validates `field_witness.coverage_proof.dependency_graph` and compares visible
witness text against a sidecar for initial burdens, terminal states, edges, roots, parallel groups,
and field diagnostics.

## Field Witness Sidecar

`field_witness` is the machine-readable reconstructibility layer. When present, it records:

- burden nodes, dependency edges, roots, and parallel groups;
- terminal states and register deltas;
- `∇·` / `∇×` diagnostics and LoopBreak data;
- `R(H,Δ)`, closure status, and `T_lang` boundary;
- non-claims and provenance/evidence metadata.

The sidecar remains diagnostic evidence. It does not prove truth, warrant, interlocutor uptake,
package-bound release-smoke status, or full formal calculus.

sidecar JSON with no network dependency.

carried the rule; the checker token still expected an older literal banner phrase and one

evidence: `python tools\check_render_modes.py` PASS.

## Reconstructibility

Visible closure witness graph = human-readable reconstructibility. A reader can recover roots,
dependency edges, parallel groups, terminal states, and closure diagnostics from the output text.

`field_witness` sidecar = machine-readable reconstructibility. A tool can validate graph shape,
terminal-state coverage, register deltas, field diagnostics, LoopBreak data, `R(H,Δ)`, closure,
`T_lang`, non-claims, and provenance metadata.

The visualizer renders either layer and can compare both. A mismatch between visible witness and
sidecar is a failed reconstructibility claim.
