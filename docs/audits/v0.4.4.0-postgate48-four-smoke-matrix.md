## Andon GATE49-MATRIX-SUBAGENT-CWD-INFRA

Symptom:
The first post-Gate48 four-smoke matrix launch did not reach the smoke harness.
All four subagents invoked relative `tools\run_staged_current_skill_smoke.py`
from `C:\workspace\ai\daee-epistemics` instead of the active worktree
`C:\workspace\ai\daee-epistemics\_tmp_stage07_v7_repair_20260603`.

Failed check:

```powershell
python tools\run_staged_current_skill_smoke.py ...
```

Representative failure:

```text
can't open file 'C:\workspace\ai\daee-epistemics\tools\run_staged_current_skill_smoke.py':
[Errno 2] No such file or directory
```

Owner file / owner surface:
Coordinator subagent-launch prompt, not a repository checker or case artifact.
The intended harness exists at
`C:\workspace\ai\daee-epistemics\_tmp_stage07_v7_repair_20260603\tools\run_staged_current_skill_smoke.py`.

5 Whys:

1. The matrix failed because the subagents invoked the runner from the parent
   workspace, where `tools\run_staged_current_skill_smoke.py` does not exist.
2. The wrong cwd existed because the coordinator prompt described the intended
   repo path but did not make `Set-Location` part of the executable command.
3. The launch was allowed to proceed because the preflight checked the main
   thread worktree, not each subagent's actual execution cwd.
4. The failure was not caught earlier because the launch prompt used relative
   paths for both the runner and run directories.
5. Recurrence is prevented by requiring every smoke subagent command to start
   with an explicit `Set-Location -LiteralPath <active worktree>`, verify the
   harness path exists, and verify the run directory absence under that exact
   worktree before invoking the runner.

Hansei:
Subagents do not inherit the main thread cwd as proof. For long, expensive
smokes, the launch command itself must bind the worktree, harness path, and run
directory before any model transport is touched.

Countermeasure:
Refresh the matrix from scratch with new run directories and commands that
begin with:

```powershell
Set-Location -LiteralPath 'C:\workspace\ai\daee-epistemics\_tmp_stage07_v7_repair_20260603'
if (-not (Test-Path -LiteralPath 'tools\run_staged_current_skill_smoke.py' -PathType Leaf)) { throw 'missing harness' }
if (Test-Path -LiteralPath '<assigned-run-dir>') { throw 'run dir already exists' }
```

Smoke B command/result:

```powershell
Test-Path -LiteralPath C:\workspace\ai\daee-epistemics\_tmp_stage07_v7_repair_20260603\tools\run_staged_current_skill_smoke.py -PathType Leaf
```

Result: PASS in the main thread. Refreshed subagents must repeat the same
preflight inside their own command before running.

Remaining blocker or closure:
Open until this documentation Andon is committed/pushed and CI/Pages are green,
then the four-smoke matrix may be relaunched with new run directories. The
failed launch produced no case output and no case-specific Stage 07 evidence.
