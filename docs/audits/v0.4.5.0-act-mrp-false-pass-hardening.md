# v0.4.5.0 ACT/MRP False-Pass Hardening

Status: `LOCAL_HARDENING_VALIDATED; V0.4.5.0_RELEASE_READINESS_BLOCKED; NO_TAG_NO_RELEASE`.

Date: 2026-06-18

## Trigger

The attached secularism output in `C:\Users\theis\Downloads\daee-epistemics-refute-secularism-output.md`
was reported as sidecar-green while the visible public body emitted ACT rows in owner-slot
round-robin order:

```text
B1_1, B2_1, B3_1, B4_1,
B1_2, B2_2, B3_2, B4_2,
B1_3, B2_3, B3_3, B4_3
```

That is coverage-complete owner-slot assembly, not runtime MRP traversal.

## Root Cause

The false-green path allowed sidecar/NAR/formal reread agreement and one terminal
`no_new_resultant` MRP to stand in for the public control transition required by the
North Star and architecture rebake invariants:

```text
Land(Bn) -> [Mid-Reread Pressure] -> R(H,Delta) -> next live burden or STOP
```

The missing guard was not ACT row syntax or local `body_ref` dereference. The rows were
mostly parseable. The missing guard was public execution order and per-burden MRP
attachment: a line-start terminal `Land(Bn):` was not distinguished strongly enough from
submove-local `Contribution-to-Land(Bn)+` / `Land(Bn)+` contribution accounting.

## Hardened Surfaces

- `tools/check_mrp_route_invariants.py` now rejects interleaved visible ACT burden
  groups, non-contiguous `body_ref` burden order, terminal MRP covering prior Land gates,
  premature sidecar `no_new_resultant`, and field-witness/formal-reread laundering.
- `tools/check_mid_reread_pressure.py` now treats ASCII `Land(Bn):` as a terminal
  line-start landing gate, matching superscript `Land(ⁿB):`.
- `tools/check_staged_runtime_handshake.py` now requires Stage07 `mrp_route_invariants`,
  public grouping, manual render, and owner ordering validation; it also reruns public
  projection integrity against the actual `release_output` text.
- `tools/build_staged_runtime_replay_record.py` now refuses to build a pass replay record
  from a selected retained output that fails public route traversal.
- `tools/run_staged_current_skill_smoke.py` now includes `mrp_route_invariants` as a
  Stage07 release validator.
- Source runtime wording in recursive-state transitions and TTP-MRP now states that
  submove contribution text is not terminal Land, and terminal public `Land(Bn):`
  immediately obligates MRP/R(H,Delta).
