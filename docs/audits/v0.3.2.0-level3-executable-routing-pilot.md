# v0.3.2.0 Level 3 Executable Routing Pilot

## Purpose

Implement an additive Level 3 path for daee-epistemics: feature extraction,
deterministic routing given features, route-plan reconstruction, route-plan
integrity validation, execution prompting, and post-output execution checking.

This pilot does not replace Level 1/2 skill behavior for runtimes that cannot
execute bundled scripts. When scripts are available, `/daee-epistemics [input]`
is instructed to use Level 3 by default for every case.

## Irreducible Limits Acknowledged

- Transformer execution ceiling: Level 3 cannot guarantee that the model will
  fully execute a route plan. Fixture 18 remains capability-bound by prior
  campaigns.
- Feature extraction ceiling: semantic features can be model-assisted and can
  vary by extractor. The pilot requires input-span support and deterministic
  routing after features exist.
- User-invocation ceiling: distributed skill use cannot force every runtime to
  execute bundled scripts. Scriptless runtimes must visibly label Level 1/2
  fallback.

## Default Invocation Policy

When scripts are available, Level 3 is the default for `/daee-epistemics`.
The wrapper command is:

```text
python scripts/daee_level3.py --input <input.md> --out <run-dir>
```

The model executes `<run-dir>/execution_prompt.md`, writes `<run-dir>/output.md`,
then Codex validates:

```text
python scripts/check_execution.py --route <run-dir>/route_plan.json --output <run-dir>/output.md
```

If the checker returns `partial` or `fail`, the user-facing answer keeps the
output but adds:

```text
PARTIAL - Level 3 execution check: <specific defect>
```

If bundled scripts cannot run, output must visibly say:

```text
Level 1/2 invocation - Level 3 wrapper unavailable in this runtime
```

## Release Claim

daee-epistemics ships with deterministic routing (`route.py`) over span-backed
feature extraction (`diagnose.py`), with route plans validated by reconstruction
(`reconstruct.py`) and post-output execution checked (`check_execution.py`).
Routing is deterministic given features. Feature extraction has interpretive
components with input-span validation. The full Level 3 pipeline is invoked via
`scripts/daee_level3.py`; users invoking a runtime that cannot execute bundled
scripts get visibly labeled Level 1/2 behavior. Highest-complexity burdens
remain bounded by transformer execution capability even under Level 3 routing.
