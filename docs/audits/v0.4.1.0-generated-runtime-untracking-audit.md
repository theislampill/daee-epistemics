## Migration Decision

Generated `skill/**` should not be tracked. It is a compiler output and package
staging tree. Tracking it made the repo encode a second quasi-source hierarchy
and forced CI to compare generated output as committed state. The corrected
shape keeps atomics in git and lets CI/local release builds regenerate the
runtime before checks and packaging.

## Verification Plan

After `git rm -r --cached skill`, the repo must pass the full structural suite,
then build a local v0.4.1.0 package from generated local `skill/**`. The
expected generated `skill/**` tracked count after migration is `0`; the local
generated runtime must still exist after build.
