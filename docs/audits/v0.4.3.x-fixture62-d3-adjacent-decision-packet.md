## Why It Is D.3-Adjacent

D.3 tracks mixed concealment / mixed pressure behavior. Fixture 62 touches the
same neighborhood because its thin case combines:

- loaded-label pressure, which is related to MM-2 carrier analysis;
- proof-standard pressure, which can release proof-method or MM proof-packet
  checks;
- source-status pressure, which can release AS-8 source-use typing;
- unknown-pattern / held-N behavior, which prevents premature noetic-family
  locking before routing.

The adjacency is real, but not clean ownership. Fixture 62 is currently framed
as a routing/noetic-reading fixture rather than a concealment-mode fixture. That
is why it should not be silently pulled into D.3 without owner acceptance.
