It binds those rows to visible ACT, `field_witness.owner_activations`,
`normalized_activation_record`, and `canonical_ir_projection`.

- structured `escape_routes_checked[]`;

  with B.1/B.2 state;
- field-witness-equivalent agreement across `B_LA`, `B_MRP`, `B_total`,
  terminal states, and graph edges.

### Working Definition of Full IR Decode for This Campaign

For this campaign, "full IR decode" does not mean arbitrary natural-language
understanding and does not mean guaranteed interlocutor uptake. It means:

```text
visible output + field_witness + NAR + canonical_ir_projection + decoded_ir
  -> checker-owned IR/state projection
  -> agreement with activation verification, graph completeness,
     collapse certificate fields, generated-burden provenance, and terminal
     route/escape-route proof where present
```

The likely next object name is `b5-full-ir-decode-v1`, unless Gemba of the
checker/schema shows a better repo-local name.

### What Can Be Done Without Model Smokes

Owner-free no-model work can:

- add a stricter optional full-IR decode object to fixtures;
- validate it against existing visible ACT, field-witness, NAR, graph, and
  certificate-sidecar evidence;
- add invalid canaries for mismatched graph edges, `generated_by`, track,
  divergence/curl, escape routes, terminal proof, owner ordering, source/sigma
  leakage, and missing opening header;
- keep schema-light outputs valid when no projection/decode object is present.

### What May Require Runtime/Default Emission

If the checker cannot close B.5 because current outputs do not emit enough
machine-facing evidence to reconstruct field-witness-equivalent state, the
campaign must stop at `PARTIAL_REQUIRES_RUNTIME_EMISSION` and open the A.13
runtime/default hard-register emission policy lane. That lane must preserve the
visible noetic-field opening read/header and must not replace it with raw
machine metadata.
