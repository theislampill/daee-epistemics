# v0.4.3.x Staged Current-Skill Harness Prototype

Status: `STAGED_CURRENT_SKILL_HARNESS_LOCAL; ONE_CASE_NEGATIVE_STAGE_EVIDENCE_RECORDED`.

Date: 2026-06-02

This packet records the first bounded staged current-skill harness prototype
after the retained replay bridge. It is repo/dev tooling only. It does not add a
new public user mode and does not replace the normal `/daee-epistemics` answer.

## Boundary

The harness boundary is:

```text
input.md
-> stage prompts
-> stage artifacts
-> handoff checker
-> composed output.md
-> graph/certificate/Grapher sidecars
-> optional B.5.4.1 checker-owned full-IR sidecar
-> retained replay comparison
```

Three layers are kept distinct:

- retained replay = no-model target shape from existing retained proof;
- staged current-skill harness = model fills bounded stages;
- final verifier sidecar = proof gate after composed output.

The public surfaces remain:

```text
/daee-epistemics
/daee-epistemics:dsl
/daee-epistemics < input.md > output.md
```

The staged harness writes scratch artifacts under ignored `.daee/`. Failed
staged runs are negative evidence, not proof. `.daee` staged artifacts remain
ignored unless later promoted through the normal retained proof-corpus gates.

## Implemented Tooling

Added:

- `tools/run_staged_current_skill_smoke.py`
- `tools/compare_staged_runtime_replay.py`

The runner has two modes:

- `python tools/run_staged_current_skill_smoke.py --self-test`
- `python tools/run_staged_current_skill_smoke.py --case-name ...`

The self-test is no-model and deterministic. It validates that the harness can
create a run directory, write stage artifacts, bind to the retained replay
record, validate the staged handoff record with
`tools/check_staged_runtime_handshake.py`, and write a hash record without
claiming model behavior.

The live run mode invokes `codex exec` with read-only sandboxing for stages
01-07, then uses checker-owned builders for stage 08 when a final output exists.
It stops on the first mandatory handoff failure and does not compose a final
proof output after a failed stage.

The comparator reports mismatch against the retained
`a9-science-source` replay shape:

```text
tests/staged-runtime-handshake/valid/retained-a9-science-source.json
```

## One Focused Staged Smoke

Run:

```text
python tools/run_staged_current_skill_smoke.py --case-name staged-a9-science-source --raw-input-path tests/retained-proof-corpus/v0.4.3.0-schema-light/valid/sidecar-backed/cases/a9-science-source/input.txt --replay-record tests/staged-runtime-handshake/valid/retained-a9-science-source.json --run-dir .daee/staged-current-skill-smokes/20260602-a9-science-source-v1 --model gpt-5.5
```

Result:

```text
STAGED_MODEL_HARNESS_NEGATIVE_EVIDENCE_STAGE_03
```

The run completed stages 01 and 02, then stopped at stage 03 because the model
returned `route_targets` as richer route objects rather than the staged contract
target list. The retained replay target expects:

```json
["B1"]
```

The model returned a list containing an object with `burden_id`, route target,
register types, pressure classes, and route basis. That is useful diagnostic
content, but it does not satisfy the current staged handoff contract because
stage 03 `route_targets` must match the stage 02 `burden_floor` exactly.

No final `output.md` was composed, no proof sidecars were built, and no retained
corpus promotion occurred.

Ignored artifact references:

- `.daee/staged-current-skill-smokes/20260602-a9-science-source-v1/records/staged-handoff-failure.json`
- `.daee/staged-current-skill-smokes/20260602-a9-science-source-v1/staged-smoke.hashes.json`
- `.daee/staged-current-skill-smokes/20260602-a9-science-source-v1/replay-comparison.md`

Replay comparison recorded eight mismatches: stage order stopped after stage
03, stage 03 route target shape differed, stage 03 owner-route shape differed,
and stages 04-08 were absent because the harness stopped honestly.
