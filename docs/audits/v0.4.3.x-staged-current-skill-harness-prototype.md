## Boundary

The harness boundary is:

```text
input.md
-> stage prompts
-> stage artifacts
-> handoff checker
-> composed output.md
-> graph/certificate/Grapher sidecars
-> optional B.5.4.1 checker-owned full-IR sidecar
-> retained replay comparison
```

Three layers are kept distinct:

- retained replay = no-model target shape from existing retained proof;
- staged current-skill harness = model fills bounded stages;
- final verifier sidecar = proof gate after composed output.

The public surfaces remain:

```text
/daee-epistemics
/daee-epistemics:dsl
/daee-epistemics < input.md > output.md
```

The staged harness writes scratch artifacts under ignored `.daee/`. Failed
staged runs are negative evidence, not proof. `.daee` staged artifacts remain
ignored unless later promoted through the normal retained proof-corpus gates.

## Stage 04 Repair Follow-Up

The follow-up Stage 04 repair tightens the ACT/body-ref handoff without opening
Stage 05+ or composing a final governed output:

- `act_targets`, `act_burdens`, `act_body_refs`, and `act_rows` are canonical
  string lists.
- Every ACT row must begin with `⟦ACT`, contain `body_ref=`, `Δ=`, and `Land(`,
  and close with `⟧`.
- ACT row body refs must agree with `act_body_refs`.
- Optional `act_row_details` may carry richer metadata, but must agree with the
  canonical burden/body/row fields.
- Object-shaped `act_rows` are normalized only when each object contains an
  explicit string `act_row`; objects without `act_row` are rejected.
- Stage 04 ACT owners, when detectable from rows/details, must be backed by
  Stage 03 `owner_routes`.
- The replay comparator can now compare only a stage prefix with
  `--through-stage`; Stage 03 owner routes compare by route identity so richer
  model metadata does not cause a false Stage 04 mismatch.
