## Boundary

The harness boundary is:

```text
input.md
-> stage prompts
-> stage artifacts
-> handoff checker
-> composed output.md
-> graph/certificate/Grapher sidecars
-> optional B.5.4.1 checker-owned full-IR sidecar
-> retained replay comparison
```

Three layers are kept distinct:

- retained replay = no-model target shape from existing retained proof;
- staged current-skill harness = model fills bounded stages;
- final verifier sidecar = proof gate after composed output.

The public surfaces remain:

```text
/daee-epistemics
/daee-epistemics:dsl
/daee-epistemics < input.md > output.md
```

The staged harness writes scratch artifacts under ignored `.daee/`. Failed
staged runs are negative evidence, not proof. `.daee` staged artifacts remain
ignored unless later promoted through the normal retained proof-corpus gates.

## Stage 05 Repair Follow-Up

The follow-up Stage 05 repair tightens the MRP/reread/terminal-state handoff
without composing a final governed output or opening Stage 06+:

- `terminal_states` must be a non-empty burden-id object and must account for
  every Stage 04 ACT burden.
- terminal-state values are controlled: `landed`, `held`,
  `held-with-reason`, `hold_partial`, `partial`, `carried-PARTIAL`, or
  `discharged-as-derivative`.
- optional `generated_burdens` must be accounted in `terminal_states`.
- `dependency_graph_edges` must be a list, and every edge endpoint must appear
  in the known routed/ACT/generated burden set.
- `no_new_resultant_proof` is required. Boolean `true` is valid only when no
  unresolved burden remains; object form requires `proved`, non-empty `basis`
  when proved, and empty `unresolved_burdens` when `proved=true`.
- optional `reread_state` uses controlled state/route tokens and cannot claim
  `STOP` while unresolved burdens remain.
- Stage 05 cannot emit final/release/verifier fields such as `release_output`,
  `field_witness`, `closure_claim`, `verifier_sidecars`, Grapher, or collapse
  certificate evidence.
- The replay comparator now supports a Stage 05 prefix and detects
  terminal-state mismatches.
