## Generalized Runtime Rule

When a case admits multiple valid noetic-structure selections, the runtime must not hardcode one
route as canonical or collapse the case into a scalar master diagnosis. The selected execution
path is the release order over the live noetic field, not the whole field itself.

Noetic structures, burdens, submoves, dependencies, registers, routes, and closure pressures are
not scalar objects. They are relational field states in token/noetic space: they can carry
directed dependency, residual outward pressure, circularity, overlap, conflict, and unresolved
route pressure. Scalar collapse is an execution failure because divergence and curl are field
diagnostics, and fields are lost when noetic structure is reduced to a one-point summary.

Every live input-anchored structure, burden, submove, dependency, or residual pressure must be
addressed, integrated, discharged as duplicate/derivative, explicitly held with reason, or carried
forward into RECURSE/PARTIAL.

## Delta / Divergence / Curl Field Accounting

- `ΔⁿB` marks an event-local burden delta.
- `Δκ` marks a collapse/closure-state delta.
- `R(H,Δ)` rereads the whole live field after a burden event or field-state update.
- `∇·` reads divergence-like residual outward pressure in an explicit target field.
- `∇×` reads circular, rotational, or unresolved cyclic pressure in an explicit target field.

`κ` is a valid closure/collapse-state target (`∇·κ`, `∇×κ`), but it is not the only target.
Burden, dependency, register, route, or noetic-field targets such as `∇·B`, `∇×B`, `∇·♥`, and
`∇×ξ` are valid when owner-defined and control-effect-bound.

FAIL if `∇·` or `∇×` is used as a transition operator, as proof-by-symbol, as a replacement for
`Δ`, as decorative prose, or on an untargeted scalar summary.

PASS only if `∇·` / `∇×` usage is target-explicit, field-state diagnostic, and tied to
`R(H,Δ)`, `κ/H`, dependency pressure, loop-breaking, hold/release posture,
PARTIAL/RECURSE/COMPLETE, or checker outcome.

## Header Wording Issue

The old banner line `source request: NONE EXPLICIT` is ambiguous for prompts like
`/daee-epistemics refute:` because it can hide that the user explicitly requested a refutation.
The corrected banner distinguishes:

- `user task: REFUTE`
- `external source request: NONE EXPLICIT`
- authority frame
- state

## NLA And Shannon Boundaries

NLA remains Natural Language Autoencoder reconstruction-fidelity discipline: Layer A / Diagnostic
IR / noetic-field banner acts as verbalizer; reconstruction/reread / `R(H,Δ)` acts as
reconstructor. If two valid noetic-structure selections exist, reconstruction fidelity prevents
either verbalization from hiding unreconstructed live burden pressure.

Shannon language remains bounded to signal, encoding, channel, noise, distortion, redundancy,
compression, and capacity. Shannon, NLA, and `∇` do not measure truth, meaning, warrant,
revelation, fitrah, or sound reason.

## Closure Criterion

Closure is licensed only when all live input-anchored structures, burdens, submoves,
dependencies, and residual pressures are landed, integrated, discharged as duplicate/derivative,
explicitly held with reason, or marked for RECURSE/PARTIAL. The final restorative response must
preserve the master deformation discovered during execution.
