### A.1 - Formal Termination Proof for the MRP Generation Chain

What it is: A written theory-document proof that the sequence of state
transitions `Sᵢ -> Sᵢ₊₁ -> ...` terminates, using the small-step state:

and depth ordering as engineering intuition. The claim that `𝔅_MRP` is
exhaustible needs a formal proof.

Required proof steps:

1. The eligible route set `R(S)` is finite at every `S`, because it is bounded by

2. Every `operate` step (`ⁿBᵢ[OP] -> Sᵢ'`) either reduces `|B_live|` when a

5. From 1-4, the computation sequence reaches `STOP`, `HOLD`, or `PARTIAL` in
