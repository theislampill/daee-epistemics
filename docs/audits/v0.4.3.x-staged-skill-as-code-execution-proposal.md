# v0.4.3.x Staged Skill-as-Code Execution Proposal

Status: `STAGED_SKILL_AS_CODE_HANDSHAKE_CONTRACT_NO_MODEL; RETAINED_REPLAY_BRIDGE_LOCAL; STAGED_CURRENT_SKILL_HARNESS_LOCAL_NEGATIVE_STAGE03`.

This packet records the owner-opened no-model architecture/prototype lane after
B.5.4.1 checker-owned sidecar adoption. It is not release notes, not package
provenance, not a model smoke, and not a public user mode.

## Decision

Keep the existing user-facing interface:

```text
/daee-epistemics
/daee-epistemics:dsl
/daee-epistemics < input.md > output.md
```

No new public user mode is introduced in this slice. File-retained
`output.md` remains the full governed answer. Staged scratch artifacts are
repo/dev harness artifacts only, and checker/harness verdicts are not
automatically claimed in normal user chat.

## Two-Layer Architecture

Layer 1: verifier sidecar.

- Existing B.5.4.1 layer.
- Catches mismatch after output.
- Uses `tools/build_b5_full_ir_projection_sidecar.py`.
- Uses retained `b5_full_ir_projection_sidecar` manifest evidence.
- Remains the final proof sidecar / retained-corpus verification layer.

Layer 2: staged skill-as-code execution.

- New no-model architecture lane.
- Structures execution before and during output.
- Model fills bounded stages only in later model-harness lanes.
- Code supplies stage order, state persistence, validation gates, mismatch
  localization, and handoff contracts.
- Checkers validate each handoff before a later harness may proceed.

## Non-Claims

This lane is not:

- scripts writing the apologetic answer;
- arbitrary natural-language-to-IR parsing;
- fresh runtime/default inline proof-mode emission proof;
- model/current-skill behavior proof;
- broad proof-mode corpus adoption;
- package, tag, upload, release, or provenance;
- D.8 cleanup;
- Graphify or ActiveGraph proof.

## Why This Fits

The repository already treats `daee-epistemics` as runtime execution
architecture over live diagnostic state rather than prompt advice. Diagnostic
IR, owner/TTP routing, burden execution, `Land(B)`, `R(H,Delta)`, NAR,
field-witness convergence, graph completeness, collapse certificates, and
Output Grapher proof sidecars already form a verifier stack.

The missing layer is pre-output discipline: a staged handoff contract that
lets future harness work localize whether failure occurred at intake, Layer A
diagnosis, routing, ACT execution, MRP/reread, field witness/NAR, release, or
verifier sidecar construction.

## Boundary

The visible governed answer remains the release surface. The staged records
are dev/harness scratch state. The verifier sidecar layer remains the final
proof authority when a proof claim is made. Graphify may help navigate files;
ActiveGraph may record ignored local sidecar events; neither proves behavior.
