## Architecture match

The safe patch aligns with the existing chain:

`Layer A / initial state-read -> Layer B -> Land(ⁿB) -> [Mid-Reread Pressure] -> R(H,Δ) -> MRP resultant -> Closure/Reconstruction Witness`.

It preserves repo-native notation: `¹B`, `²B`, `MRP(¹B)`, `R(H,Δ)`, `∇·T`, `∇×T`, `∇·B`, `∇×κ`, `𝒞(Ψᴺ)`, and `T_lang`.

## Architecture risks

- Making MRP generation-first would lose reconstructible initial burden accounting and could cause missed input-anchored burdens.
- Treating all named-worldview cases as a determinate interior kufr mode would over-certify unseen states and violate the existing lexical-vs-sharʿī caution; the output should route visible operative covering through source-owned modes while preserving the no-soul-state / no-takfīr boundary.
- Treating `clear` as impossible would break valid genuine-shubhah / already-cleared cases.

## Minimal safe patch set

- Add worked counter-case text for held-vs-generated MRP route typing.
- Teach checkers to parse Markdown-styled MRP blocks and closure-witness MRP resultants.
- Add a five-node held-route fixture and a closure-ledger regression fixture.
- Add a narrow concealment-mode checker and fixtures for surface-open / framework-concealed cases.
- Enforce source-owned concealment mode vocabulary for non-clear diagnoses: `iʿrāḍ`, `juḥūd`, `inkār`, `istikbār`, `nifāq`, or `mixed`, with loose glosses secondary.
- Preserve `clear` for positively non-operative concealment and preserve `mode-?` for unresolved interior mode.

## Deferred

- Full concealment `type` / `level` schema expansion or person-level culpability engine.
- New `ʿinād` and `shakk/rayb` concealment modes; current owners treat them as posture/doubt-route pressures, not source-owned concealment codes.
- Culpability-coded routing for sincere Muslim/ḥanīf clarification cases; shubha/shakk/rayb remains clarification pressure unless refusal signals are independently visible.
- A numeric cap on Layer A burden inventory.
- Reframing the dependency graph as MRP-only rather than closure-witness / field_witness reconstructed.

### Observed faults

- The first claimed "original goal met" proof was too broad: the real `j173`, `TST`, and

### Causes

- The generated runtime template still permitted adjacent route prose to stand where required
  MRP route fields should have appeared.
- The concealment checker only inspected the immediate Layer A block and did not treat later
  hidden-framework recoil as evidence that `clear` was unlicensed.
- Closure-witness parsing did not normalize public `¹B` notation to machine `B1` notation.
- `check_mrp_generated_burden.py` collected `held:` lines from the whole document rather than only
  the initial Layer A / initial inventory segment, so later generated-burden local held material
  could be misread as initially held.
- The generated-burden checker also assumed the generated node's Layer A must appear after the
  burden heading. Default governed output can render a local "Layer A ... for ²B" immediately
  before the generated burden heading; that is still real generated-node accounting.
- The checker treated a historical closure summary edge inside a later `no_new_resultant` prose
  line as if that STOP block had created a new graph edge. Only the `Graph delta:` field should be
  used to detect edge creation in a `no_new_resultant` MRP block.
