Status: CURRENT-CANDIDATE

## Executive result

P1 docs/index design refinement implemented.

This pass did not replace the docs/index system and did not hand-edit generated
HTML. It refined source-owned sections, template behavior, generator output,
design documentation, visual QA documentation, and non-brittle checker coverage.

## Notation preservation result

Exact daee-epistemics notation was preserved. The checker now requires critical
forms across generated output and source data, including `𝓝`, `D₀`, `Ψᴺ`,
`Ψᴵ`, `N∈𝓝`, `∇·T`, `∇×T`, `∇ route pressure`, `ⁿB`, `ⁿBᵢ[OPᵢ]`,
`Land(ⁿB)`, `ΔⁿB`, `Δκ`, `ΔⁿB{♥,ξ,Ω,σ,μ}/Δκ`,
`LoopBreak(∇×T)`, `R(H,Δ)`, `R(H, ΔⁿB{♥,ξ,Ω,σ,μ}, Δκ)`,
`𝒞(Ψᴺ)`, `T_lang`, `T_lang: Ψᴺ ⇢ Ψᴵ`,
`N_fiṭrī ∧ ʿaql ṣarīḥ`, `fiṭrah`, and `ʿaql ṣarīḥ`.

Plain-language labels were added around the notation where useful; formal
notation was not simplified, renamed, transliterated, or ASCII-normalized.

## Local Reference Library regression follow-up

A follow-up local fix corrected a Reference Library hierarchy regression where
generated role metadata became a default-visible role-card wall, with many
one-count cards dominating the source-browser path. The Reference tab now keeps
the human task first inside one coherent workspace: compact totals, a unified
search/filter bar with coarse layer/family controls, source list, and selected
generated document preview.

Full layer, family, fine-grained role/title, and raw source-map material remains
generated from `REFS`, `DOCS`, and `REF_SUMMARY`, but it is now inside the
collapsed raw-source provenance disclosure. The checker guards against the old
default-visible role-card wall, standalone summary panel, and fine-grained role
filters, and requires the selected preview to appear before raw provenance.

Latest local correction: the Reference `Source map` section is explicitly
provenance-second. Full layer breakdowns, coarse/fine role breakdowns, one-count
role/source rows, raw generated tables, and generated source metadata stay inside
the collapsed `Source map / generated provenance` disclosure below the
source-browser workspace.

The `#reference` route now resets to the browser path: the Source map disclosure
is closed, the source-browser list/preview is rendered first, and the tab scrolls
to the Reference Library/browser path rather than preserving a low audit-table
scroll position.

Latest count-summary correction: Source map layer, coarse family/type, and
fine-grained role/source breakdowns preserve their distinct meanings and exact
generated labels, then render as compact key/value count lists rather than
`NAME` / `COUNT` tables. Fine-grained counts remain searchable, row-limited, and
show-all gated; raw generated source rows remain a real table in the deepest
collapsed raw-source disclosure.

## Local Theory runtime-card flow follow-up

The repeated Theory section-heading regression was traced to treating semantic
phase/color labels as section wrappers for an otherwise runtime-ordered card
flow. The local correction keeps the formal runtime trace ordered, renders the
phase/color labels once as a thin left-side legend rail, and renders
`theory_cards` as one flat wrapping card bank sorted by source-owned
`card_runtime_order`.

Runtime execution readability now comes from six compact, non-repeating step
breaks owned in `docs/index/runtime-architecture.json`: Selection /
signal-state, Runtime registers, Route and burden, Landing and diagnostics,
Closure and restoration, and Public release boundary. These are execution
separators, not semantic phase buckets.

Highlighted notation now separates semantic color from active selection. The
selected chip, Highlighted set rows, and Related chips keep their phase/source
color; active state is shown with ring/glow/stroke and ARIA state instead of a
generic replacement highlight.
