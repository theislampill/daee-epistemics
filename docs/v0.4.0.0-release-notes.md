## Evidence Boundary

Package/release proof applies only to this v0.4.0.0 package artifact and the
current-release package-bound smoke suite recorded in `docs/release-artifacts.md`.

Static routing fixtures remain static evidence only. Retained `.daee` child-mode
samples remain local ignored evidence only. Dev-local checker PASS is not universal
semantic grading. The NLA-inspired faithfulness gate is an explanation/reconstruction
discipline; it does not claim activation-level interpretability or inspection of
transformer internals.

No new corpus ingestion, argument bank, operator family, or broad owner pack is
included in this release.
