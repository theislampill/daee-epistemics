## What's New

- Historical v0.3.1.0 render state: default `/daee-epistemics` stopped emitting full raw
  IR/ledger blocks; later governance requires compact DSL/IR visibility in default.
- The compiled package includes the four runtime metadata copies declared by
  `RUNTIME_METADATA_COPIES`: `module-catalogue.json`, `diagnostic-ir.schema.json`,
  `operative-contract.schema.json`, and `operative-contracts.md`.
- Mojibake was swept and repaired across canonical source, generated runtime bundles, release
  documentation, and checker code.
- All 103 canonical atomics reference files now carry `contract_version: "0.3.1.0"`, and the
  regenerated runtime carries the same contract surface.
- Generated runtime metadata now reports `compiler_version: "0.3.1"`.
- README release workflow now lists the full checker suite used for v0.3.1.0 readiness.
- The `runtime-grounding-v5` smoke artifacts passed the burden-completeness gate: hard fixtures
  remain hard, bounded fixtures are marked bounded-complete with explicit first-/second-/
  higher-order burden audits, and the smoke artifact checker rejects quiet hard-to-bounded
  reclassification.
