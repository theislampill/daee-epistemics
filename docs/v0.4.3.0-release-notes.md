# v0.4.3.0 Release Notes

v0.4.3.0 is a closure reconstructibility and reread-pressure release on the
`0.4.0.0` operative contract line. RC1 was an internal closeout label only; the
public release is simply `v0.4.3.0`.

## Summary

This release makes closure output more reconstructible and makes state reread less
cosmetic. It adds parseable visible closure-witness dependency graphs, a
machine-checkable `field_witness` sidecar, local/offline DAG visualization, and
Mid-Reread Pressure (MRP), a reread-time activation harness that pressures
`R(H,Δ)` after `Land(ⁿB)` before STOP / HOLD / RECURSE / LoopBreak / closure is
licensed.

Classification: schema-light executable governance calculus.

## What Changed From v0.4.2.0

### New operator: TTP-MRP — Mid-Reread Pressure

After a burden lands, `R(H,Δ)` now has a governed mechanism for testing whether
apparent new pressure is a genuine downstream dependency, a partial real burden,
hidden-framework recoil, label-pressure or doubt-churn, or a reorientation
reminder.

MRP freezes the landed `ΔⁿB`, activates matched existing pressure owners,
aggregates their findings, and licenses routing:

- Genuine new dependency → RECURSE + graph edge added.
- Partial real burden → HOLD.
- Hidden-framework recoil / label-pressure / churn → LoopBreak or STOP without
  proof-stacking.
- Stable reread → closure witness.

This prevents two v0.4.2.0 failure modes: false closure, where the runtime stops
while genuine reread pressure remains, and proof-stacking, where churn or
unlicensed recoil creates fake burdens.

MRP also makes `∇·T` and `∇×T` active reread gates during the pressure check
rather than decorative final labels.

### `field_witness` sidecar extended

The `field_witness` sidecar now supports optional `register_deltas`,
`non_claims`, `provenance`, and `reread_pressure` records.

The `reread_pressure` record captures structured MRP evidence: target burden,
reread delta, six pressure activation states, divergence/curl states, finding,
graph delta, pre-emption basis, route, and non-claims.

The `coverage_proof.dependency_graph` structure now carries machine-readable
`nodes`, `edges`, `roots`, `parallel_groups`, and `acyclic` fields with validated
`^B[0-9]+$` node IDs.

### Banner enforcement

The first visible content must be the literal `field:` line: no heading, no box
art, no prose, and no Markdown fence before it. This replaces the older
decorative banner pattern and avoids wrapping the runtime banner in Unicode box
drawing.

### Dependency graph notation finalized

The visible closure witness graph notation is now:

- `(root)` = no upstream dependency.
- `A → B` = B depends on A landing first.
- `A ∥ B` = A and B are parallel / independent at that level.

Node IDs must match terminal-state burden IDs. The graph must be reconstructible
from visible witness text alone. ASCII `A -> B` remains a legacy transport
fallback only; the preferred notation is `A → B`.

Counterexamples such as `B1 then maybe B2`, `B1/B2 related`, and `B2 after the
first thing` are invalid because they are not reconstructible dependency graph
statements.

### Entrypoint and governance cleanup

The Phase 2 pass table in `SKILL.md` was simplified into owner-file pointers so
the detailed skip/clearance rules live in `V1-diagnostic.md` and
`diagnostic-ir.md`. This is a DRY cleanup, not a runtime behavior change.

PACK-SPEC authoring notes were added to major compiled owner blocks so normative
edits route through `docs/spec-authoring-pack.md` rather than ad hoc prose.

### Deterministic proof and packaging

This release adds deterministic integrated proof through
`tools/check_reconstructibility_and_mrp.py` and package-bound artifact validation
through `tools/check_skill_package_artifact.py`.

## Smoke Before Claim

The release task runs deterministic source/runtime/docs checks, package-shape checks,
closure graph and `field_witness` checks, MRP checks, and local package artifact validation
before publishing.

Package-bound validation for this release uses:

```powershell
python tools/check_skill_package_artifact.py build\daee-epistemics-v0.4.3.0.skill --expect-version v0.4.3.0
python tools/check_release_provenance.py --provenance build\daee-epistemics-v0.4.3.0.provenance.json --package build\daee-epistemics-v0.4.3.0.skill --manifest skill\build-manifest.json --compiled-map skill\compiled-module-map.json --release-artifacts docs\release-artifacts.md
```

## Not Claimed

- Fresh live/generated-runtime LLM smoke is not claimed unless explicitly run during release.
- Cross-host/paraphrase proof remains future work.
- `T_lang: Ψᴺ ⇢ Ψᴵ` remains a transfer boundary, not guaranteed uptake.
- The package proof is bounded to the artifact checks and deterministic fixtures actually run.
