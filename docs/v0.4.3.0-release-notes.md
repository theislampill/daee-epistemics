# v0.4.3.0 Release Notes

v0.4.3.0 is a corrected-goal closure release on the `0.4.0.0`
operative contract line. The public release remains tag `v0.4.3.0`;
the release asset is replaced in this closeout only after source CI,
package rebuild, package-bound smoke, and downloaded-asset provenance
gates pass.

## Summary

This release closes the v0.4.3.0 manual-smoke regression and the expanded
IMPLEMENTAUDIT proof rows for the current release scope. The runtime now
requires the public render contract, formal MRP burden-ledger proof,
machine-readable `field_witness`, checker-derived owner activation authority,
formal reread-state semantics, register-derived burden floors, and
package-bound repeated-run stability evidence.

  owner-catalogue lookup and `body_ref` (facet recoverability, not universal
  semantic grading; see `docs/proof-class-taxonomy.md`).
- Shannon finite-fold trace discipline over the verified burden graph.
- Bounded executable grammar for `R(H,Delta)`, route-gradient, divergence, curl,
  and LoopBreak where represented in formal reread state.
- Boltzmann Brain stress behavior with HOLD/PARTIAL where absolute
  anti-fluctuation disproof remains a non-claim.

## Scope Boundaries

- Literal Shannon integral theorem is research-only in this release. No `dB`
  measure, numeric entropy, `H(Phi)`, `H_fitrah`, or convergence theorem is
  claimed.
- Literal vector calculus is not claimed. The release claims bounded
  checker-executable state-transition grammar for the represented route,
  divergence, curl, and LoopBreak states.
- `T_lang` response-closure checking is deferred to v0.4.4.0. This release
  proves structural closure and bounded language-mediated response behavior,
  not guaranteed uptake.
- Raw smoke outputs are local evidence and are not release assets.
- Cross-host/paraphrase proof is not claimed.
