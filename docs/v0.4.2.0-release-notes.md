# v0.4.2.0 Release Notes

v0.4.2.0 is a Deep Research implementation and evidence-discipline release on the
`0.4.0.0` operative contract line. It preserves daee-epistemics as a schema-light executable
governance calculus: stronger than prompt engineering, but not a full formal calculus and not a
truth meter or guaranteed-uptake system.

## Summary

This release improves the repo's evidence chain, release-proof posture, generated-docs
freshness discipline, TTP/operator checker coverage, field-operator boundary checks, and witness
marker resistance. It does not add new noetic theory and does not migrate the field calculus into
hard Diagnostic IR schema fields.

## What Changed

- Promoted generated docs freshness checking with `python tools/build_docs_index.py --check`.
- Promoted docs interaction checking with `python tools/check_docs_index_interactions.py`.
- Promoted strict TTP operator contracts with `python tools/check_ttp_operator_contracts.py --strict`.
- Promoted field-operator architecture checking with `python tools/check_field_operator_architecture.py`.
- Added bounded local release provenance checking in `tools/check_release_provenance.py`.
- Improved the manual release artifact workflow provenance self-check.
- Hardened `tools/check_live_default_witness_contract.py` against empty witnesses, marker theater,
  uptake overclaims, rote `R(H,Delta)` markers, and restorative bypass.

- Regenerated `docs/index.html` and `docs/daee-epistemics-pipeline.html`.
- Added the Deep Research implementation audit and next-handoff for follow-up investigation.
- Added direct positive and misuse routing fixtures for the fourteen modules previously tracked as
  under-fixtured in the operativity audit, plus a focused coverage checker.
- Added a minimal three-case current-release smoke skeleton: `CR-01` through `CR-03` are the
  v0.4.2.0 release-required local package-bound smokes, while `CR-04` through `CR-10` are deferred
  expanded-smoke slots for v0.4.3.0/v0.5.
- Verified the v0.4.2.0 package/provenance pair with `tools/check_release_provenance.py`.

  `21B25FF08AD36E26A57BACEC785C635F49DEC06E84A6EE191F4F8A61870913A7`. Raw smoke captures remain

## What Is Not Changed Or Claimed

- Raw current-release captures remain local diagnostic artifacts and are not committed. The release
  claims only the local three-case package-bound smoke gate performed before release.
- No hard schema migration of the field calculus was performed.
- No claim is made that daee-epistemics is a full formal calculus.
- No claim is made that `T_lang` proves interlocutor uptake.
- No claim is made that witness markers prove behavioral competence.
- No claim is made of broad live-output competence beyond the included local three-smoke package
  gate.
